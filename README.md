# Algoritmos e Lógica de Programação em Java

Exercícios resolvidos em **Java** do curso **Algoritmos e Lógica de Programação**, do professor **Nélio Alves** (Udemy, 31 horas).

Este repositório traz uma seleção dos problemas do curso resolvidos em Java, com um arquivo `.java` por exercício.

## Conteúdo abordado

- Entrada e saída de dados
- Estruturas condicionais 
- Estruturas de repetição 
- Vetores
- Matrizes

## Exercícios

| Arquivo | Tema |
|---|---|
| `Ages.java` | Exercício com idades |
| `Ascending.java` | Ordem crescente |
| `NegativeDiagonal.java` | Diagonal da matriz e valores negativos |
| `Rectangle.java` | Cálculos com retângulo |
| `Smallest.java` | Menor valor |
| `SumOddNumbers.java` | Soma de números ímpares |
| `Sumvector.java` | Soma dos elementos de um vetor |

## Como executar

É necessário ter o [JDK](https://adoptium.net/) instalado (Java 11 ou superior).

```bash
# compilar
javac NomeDaClasse.java

# executar
java NomeDaClasse
```

Exemplo:

```bash
javac Rectangle.java
java Rectangle
```
